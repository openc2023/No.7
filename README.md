# No.7
让每个人都能轻松创建自己的网站！ 🚀

## 项目简介
No.7 是一个直观易用的网站构建工具，让用户无需编程知识即可创建专业网站。

## 功能特性
- 直观的可视化编辑界面
- 丰富的组件库
- 灵活的页面布局
- 专业的文字编辑工具栏
- 页面切换和保存功能
- 分离式Header和Footer管理

## 技术栈
- HTML5, CSS3, JavaScript
- GrapesJS 可视化编辑器
- PHP 后端
- Git 版本控制

## 使用说明
1. 克隆仓库到本地
2. 配置Web服务器
3. 访问admin目录开始编辑

## 安装要求
- PHP 7.4+
- Web服务器（Apache, Nginx等）
- Git
